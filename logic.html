Execution Flow — Six Interactive Stages

STAGE 1: LOAD
1 LOAD

Load inputs A and B into internal registers.

2 DECODE

Decode opcode into MUX select & enable signals.

3 ENABLE

Enable the selected logic array or shifter.

4 COMPUTE

Gate array executes bitwise boolean computation.

5 FLAGS

Evaluate CCR flags (C, Z, N, V).

6 WRITE

Latch result into Result Register [ACC].
